Project 02

SoftStore

A software license marketplace for Jordan. Customers pick an OS or software title, select a version and warranty, and order directly via WhatsApp. Built entirely on the frontend — no backend, no database.

The Problem

Buying software in Jordan is confusing — unclear pricing, no warranty options, and no trustworthy local seller. SoftStore makes it simple: see the product, see the price, order in one tap.

How I Built It

Pure HTML, CSS, and JavaScript split across multiple files — index.html for structure, style.css + mobile.css for styling, app.js for all product logic, products.js for the product catalog, and pricingRules.js for a custom dynamic pricing engine. Prices calculate in real time based on the selected version and warranty period. The checkout is a modal that builds a pre-filled WhatsApp message and opens it directly.

Tech Stack

HTML CSS JavaScript Custom Pricing Engine

What I Learned

Separating data from logic was the right call early. When I needed to add new products or change pricing rules, I only touched one file. The custom pricing engine also taught me to think about edge cases — different products have different warranty pricing models, and getting that right took more iterations than expected.
