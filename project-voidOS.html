Project 03

Void OS

A customized Arch Linux distribution built from scratch for developers and power users. Not a reskin — every component chosen, configured, and tuned deliberately. This is the OS I actually use every day. Tagline: "ghost in the machine."

The Problem

Most Linux distros make compromises for the average user. Void OS makes zero compromises — it's built for one person's exact workflow: fast, keyboard-driven, minimal, and completely understood from the ground up. No bloat. No mystery processes. No defaults you didn't choose.

How I Built It

Started with a base Arch install — no GUI, just a terminal. Built up layer by layer:

Hyprland + Caelestia Shell — Wayland compositor with custom shell UI

Kitty + Zsh + Starship — terminal, shell, and prompt

Yazi — keyboard-driven file manager

VS Code — editor

Ollama — local AI running entirely offline

UFW Firewall — network security

Firefox / Brave — browsers

Every config file is hand-written. The system boots fast, runs light, and every keybind is mapped to muscle memory. SUPER key opens everything. The entire workflow is keyboard-first — mouse optional.

Key keybinds worth knowing: SUPER + T → terminal | SUPER + C → VS Code | SUPER + E → file manager | SUPER + V → clipboard history | SUPER + N → sidebar panel | SUPER + SHIFT + S → region screenshot | CTRL + SUPER + Space → play/pause

Tech Stack

Arch Linux Hyprland Caelestia Kitty Zsh Starship Yazi VS Code Ollama UFW

What I Learned

Understanding your tools at the lowest level changes how you use them. When you've built your OS from scratch, nothing is magic — you know exactly what's running and why. That confidence carries into everything else you build.
